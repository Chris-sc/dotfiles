# Arch Linux Hardware & System Tweaks (ASUS ROG Strix G733ZM)

This document records the custom hardware configurations, kernel parameters, module options, and packages used to get Arch Linux running cleanly on the **ASUS ROG Strix SCAR 17 (`G733ZM_G733ZM`)**.

---

## 1. Speakers & Audio Pinout Fix (`hdajackretask`)

The built-in Realtek **ALC285** (`0x10ec0285`, subsystem `0x104312bf`) speakers do not output full audio out of the box because the secondary/bass speaker amplifier pins are marked as unconnected by default.

### Packages Installed
```bash
sudo pacman -S alsa-tools alsa-firmware
```

### What Was Done in `hdajackretask`
1. Run `hdajackretask`.
2. Select codec **Realtek ALC285**.
3. Check **"Show unconnected pins"** (and **"Advanced override"** to see/set specific pin values).
4. Override pins **`0x14`** and **`0x1e`** to **Internal Speaker (LFE)** (`0x90170150`):
   - **Pin `0x14`**: Default `0x411111f0` (driver `0x99130110`) -> **`0x90170150`**
   - **Pin `0x1e`**: Default `0x411111f0` -> **`0x90170150`**
   - *(Pin `0x17` remains `0x90170110` as the primary Internal Speaker).*
5. Click **"Install boot override"** and reboot.

### Generated Files (for direct reproduction without GUI)

**`/etc/modprobe.d/hda-jack-retask.conf`**:
```ini
# This file was added by the program 'hda-jack-retask'.
# If you want to revert the changes made by this program, you can simply erase this file and reboot your computer.
options snd-hda-intel patch=hda-jack-retask.fw,hda-jack-retask.fw,hda-jack-retask.fw,hda-jack-retask.fw
```

**`/lib/firmware/hda-jack-retask.fw`** (symlinked to `/usr/lib/firmware/hda-jack-retask.fw`):
```ini

[pincfg]

0x13 0x40000000

0x16 0x411111f0
0x17 0x90170110
0x18 0x01a19c20

```

*(Note: Other test files created in `/etc/modprobe.d/` on Dec 16, 2025: `alc285-asus.conf` (`options snd-hda-intel model=asus-gaming`), `alc285.conf` (`options snd-hda-intel model=asus`), and `alsa-base.conf` (`options snd-hda-intel model=asus-zenbook`)).*

## 3. NVIDIA Hybrid Graphics & Kernel Command Line (`supergfxctl`)

### Packages & Services Installed
```bash
sudo pacman -S linux-zen linux-zen-headers intel-ucode \
               nvidia-open-dkms nvidia-utils nvidia-prime nvidia-settings \
               supergfxctl
sudo systemctl enable --now supergfxd.service
```

### `supergfxd` Configuration
**`/etc/supergfxd.conf`**:
```json
{
  "mode": "Hybrid",
  "vfio_enable": false,
  "vfio_save": false,
  "always_reboot": false,
  "no_logind": false,
  "logout_timeout_s": 180,
  "hotplug_type": "None"
}
```

**`/etc/modprobe.d/supergfxd.conf`** (auto-generated by `supergfxd`):
```ini
# Automatically generated by supergfxd
blacklist nouveau
alias nouveau off

options nvidia-drm modeset=1
```

### Kernel Boot Parameters (`/proc/cmdline`)
```text
initrd=\intel-ucode.img initrd=\initramfs-linux-zen.img root=PARTUUID=2cece568-5738-4e99-92ff-ae838cbb0d7e zswap.enabled=0 rw rootfstype=btrfs nvidia-drm.modeset=1 ibt=0
```
- **`nvidia-drm.modeset=1`**: Enables kernel modesetting for NVIDIA (required for Wayland compositors and smooth hybrid graphics).
- **`ibt=0`**: Disables Intel Indirect Branch Tracking on 12th-gen+ Intel CPUs for compatibility with NVIDIA kernel modules.
- **`zswap.enabled=0`**: Disables zswap.

## 4. Intel Wi-Fi Stability Fix (`iwlwifi`)

To fix Intel Wi-Fi power management dropouts and 802.11ax instability, created **`/etc/modprobe.d/iwlwifi.conf`**:
```ini
options iwlwifi power_save=0
options iwlwifi disable_11ax=1
options iwlmvm power_scheme=1
```

## 5. Btrfs & SSD Maintenance (`mkinitcpio` & `fstrim`)

**`/etc/mkinitcpio.conf`**:
```bash
MODULES=(btrfs)
BINARIES=(/usr/bin/btrfs)
FILES=()
HOOKS=(base udev autodetect microcode modconf kms keyboard keymap consolefont block filesystems fsck)
```

Enabled periodic SSD TRIM:
```bash
sudo systemctl enable --now fstrim.timer
```
